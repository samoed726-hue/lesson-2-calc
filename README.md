# Семейный бюджет

Статический сайт: приветственный лендинг и калькулятор семейного бюджета.
Без сервера и без регистрации — данные остаются в браузере (`localStorage`).

## Возможности

- Доходы и расходы по строкам (можно добавлять и удалять)
- Типы расходов: нужда / желание / накопление
- Сводка: доход, расход, остаток, на человека, норма сбережений
- Сравнение с правилом **50/30/20**
- Сохранение и загрузка бюджета в браузере
- Светлая и тёмная тема
- Печать сводки

## Как запустить

Откройте `index.html` в браузере (двойной щелчок) или поднимите локальный сервер:

```bash
# Python
python -m http.server 8080

# Node (если установлен npx)
npx --yes serve .
```

Затем откройте http://localhost:8080

## Как пользоваться калькулятором

1. Укажите число членов семьи.
2. Введите доходы и расходы (при необходимости добавьте строки).
3. Нажмите **Рассчитать бюджет**.
4. **Сохранить** / **Загрузить** — работа с `localStorage`.
5. Кнопка темы — в правом нижнем углу.

## Формулы

| Показатель | Расчёт |
|---|---|
| Доход всего | сумма доходов |
| Расход всего | сумма расходов |
| Остаток | доход − расход |
| Норма сбережений | (остаток / доход) × 100% |
| На человека | остаток / число членов семьи |

Правило 50/30/20: ~50% дохода на нужды, ~30% на желания, ~20% на сбережения и долги.

## Требования
